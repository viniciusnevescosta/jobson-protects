# Prospecção — Jobson Pereira Passos

## Por onde começar

1. [[FONTE_DA_VERDADE]] — referência principal sobre serviços, região e condições comerciais.
2. [[PERFIL_DE_CLIENTE]] — prioridades, critérios de qualificação e escolha de canal.
3. [[MODELO_DE_LEAD]] — formato de cada ficha com evidências, mensagem e histórico.
4. [[MENSAGENS]] — modelos por canal para personalização.
5. [[LEADS]] — índice e status das oportunidades.
6. [[FOLLOWUPS]] — próximas retomadas após contato real.
7. [[RESULTADOS]] — desfechos, valores confirmados e indicadores.

## Fluxo de trabalho

Pesquisar fontes públicas → conferir duplicidade → criar ficha em `leads/` → verificar região e oportunidade → qualificar → escolher canal com justificativa → preparar mensagem específica → revisar → marcar “Pronto para contato”.

Após uma decisão explícita de envio manual: registrar o envio real → acompanhar resposta → atualizar próxima ação/follow-up → registrar resultado. A base não executa envios nem monitora respostas automaticamente.

Usar datas `AAAA-MM-DD` e horário de São Paulo. Contato ou dado desconhecido fica “não verificado”; datas de eventos não ocorridos ficam vazias. Toda informação pesquisada precisa de URL e data de consulta. Cada registro deve distinguir fato, hipótese e condição ainda a confirmar.

## Responsabilidade dos documentos

A Fonte da Verdade prevalece em condições comerciais e atendimento. Critérios de pesquisa ficam no Perfil; dados individuais e histórico ficam na ficha; o índice e os controles resumem essas fichas. Modelos de mensagem não substituem o texto efetivamente enviado.

Não alterar a Fonte da Verdade por inferência de pesquisa. Registrar novas condições somente após confirmação do Jobson. Não cadastrar exemplos de empresas ou modelos como leads reais.
